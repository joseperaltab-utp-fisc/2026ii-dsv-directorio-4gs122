Cómo agregar tu enlace

Tu línea ya existe en la lista, con tu número y tu nombre. Lo único que debes hacer es sustituir las dos direcciones por las tuyas: la de tu página personal y la de tus prácticas y laboratorios. No muevas tu línea de sitio ni toques la de nadie más: así nadie provoca conflictos al fusionar.

  1. Haz un fork de este repositorio o clona tu copia, según lo acordado en clase.
  2. Crea una rama con tu código: git switch -c 4gs122-NN.
  3. En docs/index.html, busca tu número y cambia los dos href="#" de tu ficha por tus direcciones reales.
  4. Confirma y sube: git commit -m "Agrega el portafolio de 4GS122-NN" y git push.
  5. Abre un pull request y espéralo revisado.

Mientras una ficha conserve href="#", sus dos enlaces se ven atenuados: esa entrada todavía no está publicada.
